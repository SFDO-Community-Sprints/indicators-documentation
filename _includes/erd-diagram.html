Note: Mermaid's erDiagram grammar did NOT support classDef/style/:::class at all in v11.x (confirmed against mermaid.parse() directly) — that landed later, alongside the neo look and bundled elkjs, so this needs Mermaid 12+ (see _config.yml's mermaid.version). Below Mermaid 12, drop the :::focused suffixes and classDef line; "focus" then only highlights the table row. Note: deliberately no `theme:` key in this diagram's own frontmatter config. A diagram-level theme always overrides mermaid.initialize()'s theme option, so setting one here would permanently disable assets/js/mermaid-theme-sync.js's light/dark reactivity for this diagram (Liquid runs at build time and can't know a visitor's runtime color-scheme choice, so this can't be parametrized the way `focus` is — the only lever for runtime theme reactivity is leaving this key absent).
