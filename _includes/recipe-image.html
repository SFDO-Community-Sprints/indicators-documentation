{%- comment -%} Resolves a recipe's `image:` front matter to a usable . Accepts whatever an author would naturally paste: - a full URL https://user-images.githubusercontent.com/.../x.png - a site-absolute path /docs/images/recipes/x.png - a repo-style path docs/images/recipes/x.png (leading slash added) - a bare filename x.png (resolved under /docs/images/recipes/) Windows back-slashes are normalised. Blank / missing -> shared placeholder. Local paths are run through relative_url so they survive the path-prefixed deploys; full URLs are emitted untouched. {%- capture src -%}{%- include recipe-image.html image=r.image -%}{%- endcapture -%} ri_-prefixed internals: Jekyll includes assign into the caller's scope. {%- endcomment -%} {%- assign ri_raw = include.image | default: "" | strip | replace: "\", "/" -%} {%- assign ri_first = ri_raw | slice: 0, 1 -%} {%- if ri_raw == "" -%} {{- "/docs/images/recipes/placeholder.svg" | relative_url -}} {%- elsif ri_raw contains "://" -%} {{- ri_raw -}} {%- elsif ri_first == "/" -%} {{- ri_raw | relative_url -}} {%- elsif ri_raw contains "/" -%} {{- ri_raw | prepend: "/" | relative_url -}} {%- else -%} {{- ri_raw | prepend: "/docs/images/recipes/" | relative_url -}} {%- endif -%}
