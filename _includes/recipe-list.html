{%- comment -%} Renders every recipe assigned to this browse page as collapsible cards, alphabetical by title. The category slug comes from the page's own `category:` front matter, so browse pages never repeat their slug here. Recipes live in /_recipes/ - one file per recipe. A recipe's `category:` is always a YAML list, so `contains` here is exact array membership and nested slugs are fine (a `[contact-npsp]` recipe does NOT match the `contact` page). The one trap: a recipe that writes `category: contact-npsp` as a bare string would `contains`-match `contact` as a substring - so always use the list form. {%- endcomment -%} {%- assign recipes = site.recipes | where_exp: "r", "r.category contains page.category" | sort: "title" -%} {%- if recipes.size == 0 -%} _No recipes in this category yet._ {%- else -%} {% for recipe in recipes %} {% include recipe-card.html recipe=recipe %} {% endfor %} {%- endif -%}
